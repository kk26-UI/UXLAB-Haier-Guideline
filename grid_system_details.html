栅格系统

以可用容器宽度为判断基准，用列、沟槽与边距建立跨家电屏、移动端、平板和桌面端的一致布局秩序。

核心规则

24 列是跨设备统一的布局标尺，不代表每块屏幕都要显示 24 列。内容区域变窄时，系统可映射为 12、8 或 4 个可用列，保持信息顺序与跨列比例。

基准24 列
宽屏12 列
常规8 列
窄屏4 列

同一组件可以用 24 列跨度记录设计意图，再映射到各档位的可用列数。例如半宽区域可表达为 12/24、6/12、4/8、2/4。

栅格构成

栅格由容器、边距、列和沟槽共同组成。建议栅格系统的网格大小选定8作为栅格系统的原子单位。

从硬件分辨率到设计尺寸

分辨率只决定像素数量，不能直接决定栅格。先得到逻辑宽度，再选档位。

  1. 1. 确认物理像素以横向像素为例：1280 pt、1920 pt。
  2. 2. 除以系统缩放倍数逻辑宽度 = 物理宽度 ÷ DPR / Density。固定嵌入式画布若不缩放，可视为 1。
  3. 3. 扣除不可用区域减去系统栏、固定导航、圆角裁切、包边和安全区。
  4. 4. 依内容宽度选档跨过断点时重排与折叠，不进行整体等比缩放。

跨档位的组件行为

重排

从 12 列降到 4 列时，8+4 主次布局改为两个 4 列区块，主任务在前；不要把两栏同比缩窄。

跨列

同一组件建议映射：4/4 → 6/8 → 8/12。文本正文在大屏仍控制在约 6–8 列，避免行长失控。

固定与流动

列与容器可流动；沟槽在同一档位内保持固定。达到最大容器宽度后，只增加外侧留白。

方向变化

横竖屏切换后重新测量可用宽度。保持信息优先级和阅读顺序，不保证元素物理位置不变。

设计与验收清单

  • ✓ 设计稿标注视口、缩放倍数、可用宽度与安全区
  • ✓ 页面主体边缘、卡片和关键控件对齐列线
  • ✓ 每个关键断点都有明确的跨列与重排规则
  • ✓ 超过最大容器宽度后不继续拉宽正文
  • ✓ 触控目标尺寸依据硬件距离规范，不随列宽压缩
  • ✓ 200% 字号或长文本下不发生遮挡与溢出
  • ✓ 横竖屏、分屏、系统栏出现时按容器重新计算
  • ✓ 在真实硬件上验证圆角、包边、视距和可触达区
例外：图表、视频和沉浸式背景可跨越列与沟槽，但其标题、图例、操作入口和数据标注仍应对齐栅格。
