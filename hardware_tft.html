TFT 屏幕

面向家电全彩图形显示与触控界面的设计规范。以真实硬件环境中的清晰、直接、稳定和可恢复为首要标准。

设备特征

开始设计前，先以产品形态、安装方式和主要任务定义界面，而不是直接套用移动端页面。

显示

TFT 能承载图形、文字、色彩与动态状态，但可用面积、亮度、可视角度和表面反射受硬件限制。内容密度必须以量产屏幕为准。

使用姿态

屏幕通常固定在产品上，用户可能站立、俯视或侧视，并在移动中快速操作。界面需适应不同身高、视距和环境光。

输入

产品可使用触控、实体按键、旋钮或语音，也可能组合使用。所有输入方式需指向同一套状态和操作结果。

交互任务

家电任务既包含开机、启动等快速操作，也包含模式配置和运行监控。离开后返回界面，应能继续理解当前状态。

色彩标准补充

指标 含义（体验视角） 现行国标/国际标准 执行标准
色域 屏幕能呈现的颜色范围，影响食材、织物和影像的色彩是否丰富。

GB/T 18910.61—2021 第 5.10 节规定色域覆盖率的测试方法，无统一强制百分比。sRGB 是互联网和家电界面的常用基准。原资料以 100% sRGB 约对应 72% NTSC 作为选型参考。DCI-P3 可呈现更鲜艳的色彩。
MUST ≥ 100% sRGB

或等效 ≥ 72% NTSC 覆盖率。

TARGET ≥ 90% DCI-P3

须标注覆盖率、测试标准和色域空间。色域容积不能代替覆盖率。
色深 颜色过渡的细腻程度，影响渐变背景和暗部是否出现色带。

无强制国际限值。行业常见分级为 6-bit（262K 色，渐变易断层）、8-bit（16.7M 色，家电界面基准）和 10-bit（约 10.7 亿色，过渡更细腻）。6-bit 加 FRC 抖动可模拟 8-bit 观感。
MUST 原生 8-bit（16.7M 色）
TARGET 10-bit

采用 FRC 时，规格书须注明原生位数与 FRC 后位数，并验证静态渐变无明显色带。仅标注 256K 或 262K 色不满足体验基准。
色准（ΔE） 屏幕显示颜色与参考颜色的偏差，影响正红色和肤色等颜色的还原。

无统一强制限值。消费级参考为 ΔE ≤ 3（如 T/TAF 246—2024），部分采购规范要求 ΔE ≤ 1–2。测试须注明色块数量、标准光源和色差公式（如 CIEDE2000）。
MUST 平均 ΔE ≤ 3
TARGET 平均 ΔE ≤ 2

适用于中高端。报告应纳入最大 ΔE，供应商须提供基于标准色卡（如 ColorChecker）的实测报告。
色度均匀性 屏幕不同区域的颜色一致程度，影响大面积纯色背景是否出现四角偏黄或偏蓝。

ISO 9241-307 包含色度不均匀性的人因评估框架。相关研究常以 Δu′v′ ≤ 0.02 为参考。LED 显示屏采购中常见 Cx、Cy 偏差要求在 ±0.002–0.003 量级，TFT 领域无统一限值。
MUST ΔCx、ΔCy ≤ 0.010

采用 9 点或 13 点白场测量。等效 Δu′v′ 限值为 ≤ 0.010–0.015。

TARGET ΔCx、ΔCy ≤ 0.005

或 Δu′v′ ≤ 0.005。测试须注明画面（白场或灰场）和点位。
对比度（静态） 同一画面内最亮白与最暗黑的亮度比，影响暗部层次是否发灰。

GB/T 18910.61—2021 第 5.5 节规定测试方法，要求关闭局部调光，未设统一最低限值。行业采购可见 ≥ 3000:1、≥ 5000:1 等参考要求。动态对比度（如 100000:1）不能作为静态对比度的体验依据。
MUST 暗室静态对比度 ≥ 1000:1

基础可读要求。中高端须达到 ≥ 1500:1。

TARGET ≥ 3000:1

验收与规格书须注明数值为关闭局部调光后测得的静态对比度。
视角色偏 视线偏离屏幕法线时的颜色变化，影响侧站或弯腰操作时的显示效果。

GB/T 18910.61—2021 第 5.6 节规定视角色偏的测试方法，未设限值。ISO 9241-307 相关实践以 0.02 作为色度一致性的参考量级。

EBU 的灰阶跟踪以 Δu*v* 表示色差。1.0 为可见性参考，0.5 为使差异不可见的容差。本卡的执行阈值采用 Δu′v′ 色度差。 EBU Tech 3320
MUST Δu′v′ ≤ 0.02

在水平和垂直 45° 视角下，相对于法线白点测量。

TARGET Δu′v′ ≤ 0.010

或在 60° 视角下仍满足 Δu′v′ ≤ 0.02。供应商须提供指定角度的色度偏移数据。仅标注 178° 可视角度无法验收。

设计原则

通过正反案例对照，快速判断 TFT 界面是否满足核心任务、触控与认知一致性的要求。

内容优先

突出当前状态、核心任务和下一步操作。减少遮挡内容的弹层与无必要的全屏跳转，让用户始终知道设备正在做什么。

触手可及

高频与关键操作放在自然可达区域，避开屏幕边缘和易误触位置；危险操作与高频操作保持距离。

一致可预期

相同功能使用一致的名称、图标、位置与反馈。实体控制和屏幕控制不得出现相反逻辑或不同状态。

渐进呈现

首屏只提供完成核心任务所需的信息；低频参数通过展开、二级页或分步流程呈现，并明确返回路径。

尺寸与触控

下列尺寸均指量产屏幕上的物理尺寸。视觉对象可以小于触控热区，但热区不得相互重叠。

≥ 12 mm主要触控目标边长
≥ 8 mm紧凑控件最小热区
≥ 2 mm相邻热区净间距
≥ 4.5 mm主要操作文字字高
注意：8 mm 仅适用于空间受限的低风险次要操作；高频、关键及运行控制应优先采用 12 mm 或更大热区，并在整机上验证。

布局与适配

以可用显示区域和观看条件响应，不按屏幕英寸直接缩放整套界面。

标准要求验收重点
安全区域核心内容、返回和启动操作避开圆角、黑边、开孔及装配遮挡区。以结构图和量产样机复核四边可见范围。
视觉层级按“当前状态—主要任务—次要信息”排序，关键内容位于首个视线落点。3 秒内识别设备状态与主要操作。
栅格对齐标题、数据、控件和卡片共享稳定的对齐线与间距节奏。不同页面切换时主控位置不跳动。
尺寸适配优先重排、隐藏低优先级内容或分页；不得等比缩小到可读与可触下限以下。覆盖目标产品的最小与最大有效画布。
语言适配为长文案、单位和数字预留弹性空间，支持中英文及文本扩展。文字不截断、不覆盖控件、不改变任务顺序。

交互与反馈

操作立即反馈

触发后立即呈现按下、选中或加载状态。执行超过 1 秒的任务需显示进度或持续状态，避免用户重复操作。

状态持续可见

运行模式、剩余时间、温度、连接和异常等关键状态需保持可见；不可只依赖瞬时提示。

关键操作可恢复

停止、取消、删除和恢复出厂设置需区分风险等级。不可逆操作必须确认，可逆操作优先提供撤销。

中断后保持上下文

息屏、锁屏、故障提示或用户暂时离开后，返回时应保留合理的任务进度，并明确设备是否仍在运行。

可读性与无障碍

不得仅用颜色、动画或声音表达状态；信息需在常见家居环境光与可视角度下被理解。

文字

保持清晰层级

正文与背景对比度至少 4.5:1，大号文字至少 3:1；字号、字重和行距需在真机上复核。

状态

使用多重线索

选中、警告和禁用状态同时使用文字、图标、形状或明暗变化，不把颜色作为唯一线索。

动态

服务于理解

动效用于说明状态变化与空间关系，避免无意义循环和过度位移；提供静态结果且不阻塞操作。

设计与验收清单

✓ 首屏可识别当前状态、主要任务与下一步

✓ 关键触控目标达到 12 mm 并保留足够间距

✓ 所有页面拥有稳定、明确的返回路径

✓ 触控、按键、旋钮和语音状态保持一致

✓ 加载、运行、完成、禁用与故障反馈完整

✓ 危险操作有防误触、确认或撤销机制

✓ 最小画布、长文本和异常数据均不破版

✓ 在量产屏幕、真实视距、角度与环境光下验证
